Server Global — Sinkronisasi Semua Perangkat

Developer pasang URL JSON sekali di sini. Semua perangkat user akan otomatis dapat config terbaru setiap buka website. Cocok untuk update API, foto profil, iklan, dan pengaturan lainnya tanpa sentuh kode.

Cara pakai (coding only, tanpa app/website kedua):
1. Unduh file veyzen-sync.php (link di bawah chat)
2. Upload ke folder YANG SAMA dengan pandzz-ai.html di hosting kamu
3. Buka file itu, ganti SECRET_KEY jadi kata sandi rahasia kamu sendiri
4. Isi URL + Secret Key di bawah ini, lalu klik Push

Kunci Domain (Anti-Clone)

Domain resmi website ini. Kalau ada yang clone lewat tools "web to zip" lalu di-hosting di domain lain, chat AI TIDAK AKAN berfungsi — layar akan menampilkan "Salinan Tidak Sah". Kosongkan untuk nonaktifkan (tidak disarankan setelah live).

Tersimpan ✓

Catatan: siapa saja yang tahu URL sync ini bisa MEMBACA config (supaya semua user bisa sinkron). Simpan Secret Key baik-baik — cuma itu yang melindungi dari orang lain menulis/push ke server kamu.
